# Frontend Phase

This phase introduces a responsive Next.js web experience for customer, merchant and admin roles.

## Implemented
- Public marketing home
- Phone OTP login
- Role-aware routing after login
- Village/store discovery
- Store catalogue
- Add-to-cart flow
- Cart view
- Customer orders
- Merchant workspace shell
- Admin operations shell
- Typed API client
- React Query provider
- Docker-ready web service

## External integrations intentionally pending
Real SMS, payment gateway, maps/geocoding, push notifications, object storage and production domains require credentials or commercial provider selection.
